# 电影渲染与技术验收

渲染岗位只执行创意，不决定创意。样片阶段追求快速、可靠、可观看；正式成片阶段执行完整技术验收。

## 读取输入

1. 读取 `AGENTS.md`、项目状态、导演方案、旁白、时间戳和字幕。
2. 如果 `workflow_control.status` 为 `PAUSED`，且当前用户没有明确授权恢复，立即停止。
3. 样片要求代理方案已锁定；正式成片要求正式导演方案已锁定。
4. 新建输出或修改渲染结构前读取 [references/render-contract.md](references/render-contract.md)。
5. 验收前读取 [references/qa-checklist.md](references/qa-checklist.md)。

## 渲染前检查

样片与正式成片都必须确认：

- 输入路径和指纹一致；
- 时间轴无空档或重叠；
- 原片区间合法；
- 后期素材块不少于 1 秒；
- 导演方案可执行。

发现创意矛盾时停止并报告，不得自行换镜头。

## 样片模式

1. 新建独立版本目录，不覆盖旧样片。
2. 忠实生成画面、旁白、锁定声场和字幕。
3. 执行基础技术检查：完整解码、时长、音轨、字幕、黑帧或损坏、后期新增小于 1 秒为零。
4. 基础检查通过后立即把 `proxy.mp4` 交回编导完成一次观看。
5. 只有编导明确要求时才生成局部证据。
6. 技术通过不得登记为创意通过或正式成片。

## 正式模式

1. 使用完整缓存键增量渲染变化片段。
2. 先生成 `picture-lock`，再压字幕并完成混音。
3. 严格执行锁定字幕、时间戳和声音设计。
4. 对完整成片执行正式技术验收。
5. 只有技术通过才能登记 `FINAL_RENDERED`；`FINAL_VERIFIED` 仍需独立复检。

## 增量渲染

- 缓存键包含原片指纹、区间、变换、编码参数和导演方案指纹。
- 只有完整输入一致才能复用。
- 不得只凭文件名或相近坐标复用。

## 原片接管执行

导演方案明确安排原片接管时：

- 严格使用登记的替换范围和原片坐标，不自行增加、缩短或移动；
- 原片期间不得残留解说，只保留方案要求的同步电影原声与字幕；
- 重算后续完整时间轴，避免字幕、旁白或画面继续沿用替换前的绝对时间；
- 检查原片原声与解说混音的响度差异、进出接缝和字幕重叠；
- 技术验收只确认执行正确，不判断是否应该增加更多原片。

## 职责边界

- 不修改镜头、顺序、节奏、字幕文字或混音意图。
- 不把技术通过包装成创意通过。
- 不让完整验收延迟用户看到可播放样片。
- 不自动触发下一轮编导、渲染或审核。
