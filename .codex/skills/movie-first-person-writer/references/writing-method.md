# 第一人称电影解说写作方法

## 建立主观叙事发动机

写作前先确定五个互相咬合的要素：

1. **原始伤口或需求**：控制主角的遗憾、渴望或恐惧。
2. **行为承诺**：因为这道伤口，主角绝不愿放弃什么，或者一定要完成什么。
3. **致命盲点**：什么信念让陷阱对主角显得可信。
4. **逐级选择**：主角主动做了什么，而不是旁边发生了什么。
5. **命运回声**：结局如何扭转或惩罚开场时的需求。

可以使用这条心理主线：

`伤口 → 承诺 → 调查 → 局部成功 → 主动相信 → 不可逆行动 → 命运回声`

## 控制第一人称信息边界

为每个关键事实记录：

| 事实 | 我当时相信什么 | 我后来知道什么 | 原片最终证明什么 |
|---|---|---|---|

文稿只能在正确时点揭露前两列。使用后来视角时，必须通过“后来我才明白”等语言明确标记，不得无缘无故变成全知叙述。

不得让第一人称主角：

- 描述自己从未发现的画外阴谋；
- 在证据出现前说出某具身体里的真实身份；
- 在相关调查发生前解释超自然机制；
- 把其他人物的私下动机当作确定事实；
- 用结局知识抹平前期真实存在的不确定性。

## 安排信息揭露

- 用即时危险、矛盾或不可逆后果开场，但不要直接解释完整反转。
- 尽早建立主角的情感弱点，使后续选择显得不可避免。
- 让物体和动作承担说明功能，例如被丢弃的纸箱、消失的镜子、锁门、污迹、钥匙、照片或重复习惯。
- 只有主角遇到证据后，才揭露相应规则。
- 每一步调查都要产生会改变行为的结果。
- 在原片解决疑问前，保留不确定。
- 结尾解释压缩成少量不可否认的身份或后果结论。
- 用完成开场伤口的画面或句子收尾，不添加空泛道理。

## 为画面和声音写作

- 优先写能对应具体可见动作的句子。
- 避免“更可怕的还在后面”之类空洞煽动，除非下一画面立即兑现。
- 不要让事实罗列速度超过观众看清证据的速度。
- 一个动作或情绪仍在推进时，允许同一连续画面承载相邻多句旁白。
- 只有原片对白能真正证明规则、求救、背叛、身份或后果时，才保留它。
- 用标点和分段制造可表演的呼吸，不要让所有句子长度一致。
- 保证姓名和术语可读；必要时附读音说明。

## 重写原则

用户认为整稿不好或明确要求“重写”时，重新设计开场钩子、心理主线、信息顺序、升级过程和结尾。不得只替换同义词。保留旧稿并新建版本。

用户只指出局部事实或逻辑问题时，只修改对应范围，同时检查相邻因果是否仍然成立。
