# 火山引擎语音识别后备流程

只有供应商没有原生时间戳，或者现有音频需要重新生成时间轴时，才读取本参考。

## 已验证接口合同

- 使用 `POST https://openspeech.bytedance.com/api/v1/vc/submit` 提交二进制音频。
- 使用 `GET https://openspeech.bytedance.com/api/v1/vc/query` 查询结果。
- 两个请求都使用 `Authorization: Bearer; <VOLCENGINE_TOKEN>` 认证。
- 中文旁白设置 `appid=<VOLCENGINE_APPID>`、`language=zh-CN` 和 `caption_type=speech`。
- 提交成功时返回代码 `0` 和任务 `id`。
- 查询代码 `2000` 表示仍在处理；代码 `0` 表示返回最终结果。

最终响应中的 `utterances` 为句级结果，每个 `words` 项包含：

```json
{
  "text": "我",
  "start_time": 80,
  "end_time": 240
}
```

时间值表示从音频起点开始计算的毫秒数。

## 密钥加载顺序

程序依次检查：

1. 当前进程环境；
2. 明确传入的 `--env-file`；
3. 本技能的 `.env`；
4. `VOLCENGINE_ENV_FILE` 指向的文件。

不得输出应用编号、令牌、认证请求头或令牌前缀。

## 输出处理

- 使用 `--output-json` 保存完整查询响应；它是字级时间戳的事实源。
- 需要句级字幕时，同时使用 `--output-srt`。
- 接受时间轴前，将识别文字与已知配音文稿对比。即使时间位置可用，语音识别仍可能把姓名识别错误。
- 不得根据音频传输数据块推测字词边界。

## 常见错误

- `1001`：请求参数无效或缺失。
- `1002`：令牌无效、过期或未获授权。
- `1003`：请求超过频率限制。
- `1004`：账号额度不足。
- `1012`：音频无效或无法解码。
- `1013`：没有检测到语音。
- `2000`：任务仍在处理中，继续轮询。
