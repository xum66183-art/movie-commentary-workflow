# v0.4 优化范围与验收

按顺序执行，保留八技能和唯一正式状态源，不调用真实付费服务。

1. 统一锁读取：artifact/path、项目相对路径、指纹、暂停状态与用户确认；先写回归测试。
2. 付费任务：操作目录跨进程互斥、按内容的保护、单次请求/字符预算、显式可配置估价和用量收据；未知结果不自动重发。
3. 合成示例：在仓库外生成媒体、模拟旁白、索引和锁定方案，贯通后续渲染及技术验收；不伪造用户认可或人工审片。
4. 通用渲染：执行已锁定、限定可支持的画面/声音方案；精确时轴、字幕、显式原声、音乐增益、指纹与缓存；不支持的指令报错，不猜测创意。
5. OCR 后处理、可回滚升级、版本/配置诊断。
6. Linux/macOS CI、最小打包安装检查、完整离线测试、公开边界扫描；通过后发布 GitHub。

行为底线：不改真实影片与声音；不自动改文稿/镜头/正式状态；不覆盖旧成片；不得把技术通过写成 FINAL_VERIFIED。所有生成媒体和缓存只在私有目录或临时目录。无需新增第三方依赖。
